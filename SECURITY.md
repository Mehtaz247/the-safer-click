# Security and privacy

Report a security issue privately through the repository owner's GitHub contact route rather than publishing credentials or exploit details in a public issue.

The site is static, uses no cookies, embeds no third-party scripts, runs no advertising, and collects no form submissions. Its build and publishing operator stores credentials only in ignored local env files or GitHub Actions encrypted secrets. The model-facing remote operator cannot modify workflow definitions, credentials, spending controls, its safety kernel, or append-only run history. Untrusted research pages are passed as evidence data and are never executed. Source content must not include personal reader data or private correspondence.
