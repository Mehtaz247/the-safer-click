Featured guide

Where to Keep Backup and Recovery Codes

Keep the code reachable when your usual device or account is unavailable—but not exposed beside the password it can bypass.

  • Keep at least one paper copy in a secure place you can reach without the phone, computer, or account the code protects.
  • Do not make the only copy depend on the same device or cloud account you may be locked out of.
  • Treat every code like a spare key: do not share it, replace it if exposed, and mark single-use codes after use.
