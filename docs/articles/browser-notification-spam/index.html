A Website Keeps Sending Alerts: Review Browser Notifications

Stop unwanted website alerts in browser settings, without following the alert's own instructions or switching off every useful notification.

Published October 27, 2026Updated October 27, 20263 min read

The short version

  • Open browser settings independently rather than clicking the unwanted alert.
  • Block notifications for the specific website you no longer want to hear from.
  • A notification permission and a pop-up window are different; use the matching control.

Next evidence review: February 24, 2027

First, identify the kind of interruption

Microsoft distinguishes website notifications from pop-ups that open inside a browser window, another window, or a tab. It also says Edge website notifications can appear even when Edge is closed. An alert outside the page therefore does not, by itself, establish that malware is installed.

Our recommendation is to note the website or browser named on the alert, then open the browser's own settings. Do not use a warning's cleanup button or support number to investigate it. This guide covers desktop Chrome and Edge; mobile browsers, operating-system alerts, extensions, and managed work devices may use different controls.

Chrome on a computer: block the specific site

Google's documented route is More, Settings, Privacy and security, Site Settings, then Notifications. Under Not allowed to send notifications, choose Add, enter the site's web address, and add it to the blocked list. Check the address carefully so that you block the intended site, not a similarly named service.

Chrome also offers quieter permission prompts. Google explains that these replace an interrupting permission pop-up with a bell by the address bar; they are not the same decision as blocking a particular site's notifications. Our default is to block the unwanted source first, then decide separately whether future permission requests should be quieter.

Edge on a computer: review site permissions

Microsoft's current route is Settings and more, Settings, Privacy, search, and services, Site permissions, then All sites. Select the website, find Notifications, and choose Block. This settings route avoids visiting the unwanted site just to change its permission.

Microsoft also documents a site-information menu beside the address bar: Permissions for this site, Notifications, then Block. That route is useful on a site you deliberately trust and already have open. The setting is reversible: Microsoft says choosing Allow in that menu resubscribes you. Do not re-enable an unwanted sender merely because its next message asks you to.

Check the result before making broader changes

Our suggested test is small: confirm that the intended address is blocked, then observe whether that sender's alerts stop. If interruptions continue, check whether they name another site, another browser, or an installed app. Do not treat a different source as proof that your first settings change failed.

If the interruption is a new tab or window instead, use the browser's separate pop-up controls. If you installed software, gave remote access, entered credentials, or paid because of a warning, blocking notifications is not a complete response. Use the exposure-based recovery guidance in our phishing-click and tech-support-warning guides, or contact your established IT team for a work device.

  1. Identify the named sender without following its instructions.
  2. Block that site's notification permission in the correct browser.
  3. Observe the result and investigate any remaining interruption by its actual source.
